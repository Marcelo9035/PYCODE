SOBRE ESTA EXPERIÊNCIA

Uma bancada. Um fluxo mais claro.

O PyCode Builder é um protótipo de interface para organizar o empacotamento de projetos Python no Windows.

O que esta demonstração faz

Lê arquivos `.py` localmente para visualizar o código e simula etapas de build na tela. Não envia nem executa código, não chama PyInstaller e não cria arquivos `.exe`.
